# Plano de Estudos (site local)

Requisito: Node.js 22.13 ou superior (use a versão LTS).

1. Abra o terminal dentro desta pasta.
2. Rode: npm start
3. Abra http://localhost:3000

Os dados que você marcar ficam no arquivo estudos.db (SQLite), nesta pasta.
Para fazer backup, copie esse arquivo. Para zerar tudo, apague-o.
