# Caderno

Plataforma de estudos local. Nada para instalar além do Node.js 22.13 ou superior (versão LTS).

1. Abra o terminal dentro desta pasta.
2. Rode: npm start
3. O navegador abre sozinho em http://localhost:3000

Os dados ficam em caderno.db (SQLite) e os PDFs na pasta arquivos. Para fazer backup, copie os dois.
Para zerar tudo, apague caderno.db e rode npm start de novo.

No Windows, também dá para abrir dando dois cliques em iniciar.bat.
